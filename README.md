# ULY DALA — сайт

Сайт премиального ивент-агентства ULY DALA. Вся концепция и правила — в [CLAUDE.md](CLAUDE.md).

## Что нужно установить один раз

1. **Node.js 22.12 или новее** (рекомендуется 24): https://nodejs.org → кнопка LTS.
   Проверить: `node -v` в терминале.
2. В папке проекта выполнить:

```bash
npm install
```

```bash
npm run e2e:install
```

Первая команда скачивает библиотеки проекта, вторая — браузер Chromium для автотестов.

## Запуск на своём компьютере

```bash
npm run dev
```

Откройте в браузере http://localhost:3000 — вас перенаправит на русскую версию.
Другие языки: http://localhost:3000/kk и http://localhost:3000/en.
Остановить сервер: `Ctrl + C` в терминале.

## Проверки

| Команда             | Что делает                                                   |
| ------------------- | ------------------------------------------------------------ |
| `npm run typecheck` | Проверка типов TypeScript                                    |
| `npm run lint`      | Проверка кода ESLint                                         |
| `npm run format`    | Автоматически выравнивает оформление кода (Prettier)         |
| `npm run test`      | Модульные тесты (Vitest)                                     |
| `npm run build`     | Production-сборка                                            |
| `npm run e2e`       | Тесты в браузере (Playwright). Сначала нужен `npm run build` |
| `npm run check`     | Всё сразу по порядку — запускайте перед каждым коммитом      |

## Переменные окружения

Шаблон — в [.env.example](.env.example). Скопируйте его в `.env.local` и заполните.
`.env.local` не попадает в git — секреты туда и только туда.

## Структура

Описана в [CLAUDE.md](CLAUDE.md), раздел 7. Коротко:

- `src/app/[locale]/` — страницы; `kk`, `ru`, `en`, русский по умолчанию.
- `src/components/` — интерфейс (ui, layout, sections, brief).
- `src/canvas/` — 3D-сцены. `src/motion/` — анимации.
- `src/content/` — тексты. `src/lib/` — общие функции. `src/server/` — заявки.
- `e2e/` — тесты в браузере. `docs/` — документация.
