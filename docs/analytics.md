# Аналитика (CLAUDE.md, раздел 14)

Своя аналитика без сторонних сервисов: `track(event, props)` → пакет → `POST /api/t` → строка JSON
в журнале сервера (`"scope":"analytics"`). Журнал собирает хостинг (на Vercel — Log Drains в любое
хранилище логов); отчёты строятся по полям `name`, `props`, `quality`, `path`.

## Почему без баннера согласия

- Нет cookie, localStorage и других записей на устройстве для аналитики.
- Нет идентификатора человека: `pv` — случайный id одного просмотра страницы, живёт только в памяти.
- Нет IP, User-Agent, имени, телефона, email, дат, комментариев. Сервер принимает только события
  из закрытого словаря (`src/server/telemetry/schema.ts`): неизвестное свойство — весь пакет отклоняется.
- Пользователи с Global Privacy Control или Do Not Track не отправляют события вовсе.

По нашей оценке, это не персональные данные, и согласие на них не требуется — подтверждает юрист
заказчика вместе с решением о хранении заявок (раздел 14, TODO(legal)).
**Если заказчик выберет Яндекс Метрику или Google Analytics** (cookie, отпечатки, передача за рубеж),
понадобятся баннер согласия до загрузки счётчика и решение юриста — TODO(legal).

## События

| Событие                 | Свойства                                                                 | Когда                                                                       |
| ----------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| `fork`                  | `audience`: corporate / family / all                                     | выбор в развилке главы 2                                                    |
| `cta`                   | `cta`: brief / menu / visit / fazenda / home / format; `place`; `format` | клик по CTA; `place` — глава или хедер/меню/футер/окно                      |
| `brief_start`           | `form`: brief / menu / visit                                             | первый фокус в форме                                                        |
| `brief_field`           | `form`, `field`; `value` — только у полей-списков                        | поле впервые заполнено (у списков — каждый новый выбор)                     |
| `brief_submit`          | `form`, `eventType`                                                      | заявка принята                                                              |
| `brief_error`           | `form`, `kind`: invalid / error / rateLimited; `fields` — имена полей    | ошибка отправки                                                             |
| `whatsapp`, `call`      | `place`                                                                  | клик по WhatsApp / телефону                                                 |
| `presentation_download` | `place`                                                                  | скачивание презентации                                                      |
| `visit_request`         | `place`                                                                  | отправлен запрос просмотра фазенды                                          |
| `menu_open`             | —                                                                        | открыто меню                                                                |
| `brief_mode`, `sound`   | `on`                                                                     | «Коротко» / звук переключены пользователем                                  |
| `scroll_depth`          | `chapter`, `index`, `of`                                                 | максимальная глава — при уходе со страницы                                  |
| `quality`               | `tier`: high / medium / fallback; `reason`                               | уровень определён; понижение (Firefox), fallback (потеря контекста, шейдер) |
| `web_vital`             | `metric`: LCP / INP / CLS / FCP / TTFB; `value`; `rating`                | реальные Core Web Vitals (библиотека web-vitals)                            |

В каждом событии также: `locale`, `path` (без query), `quality` (уровень на момент события —
так Core Web Vitals разбиваются по уровням качества), `mode` (кино / «Коротко»), `t` (мс от загрузки).

## Как посмотреть в отладке

- В консоли браузера: `window.__events` — последние 200 событий.
- С `?debug` в адресе — каждое событие строкой `[analytics] …` в консоли.
- Вкладка Network → запросы `t` (пакеты уходят через 2 с тишины и при уходе со страницы).
- В журнале сервера: строки `{"level":"info","scope":"analytics",…}`.

Автотест: `e2e/telemetry.spec.ts`.
