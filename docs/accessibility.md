# Доступность: аудит WCAG 2.2 AA (CLAUDE.md, раздел 10)

Аудит — 1 октября 2026. Автоматика: axe (все страницы × 3 языка, и в состояниях с готовым 3D),
свой замер контраста по пикселям над 3D, обход клавиатурой, дерево доступности Chrome.
**Ручной прогон VoiceOver и NVDA — ниже, его нужно пройти человеку** (скринридер не автоматизируется
надёжно; автотест повторяет путь по ролям и именам, как ищет скринридер).

## Проверено — в порядке

- **axe — 0 нарушений**: 15 типов страниц × kk / ru / en; главная с готовым 3D в каждой главе
  (десктоп и телефон), открытое меню, бриф с ошибками, fallback, reduced motion.
- **Контраст над 3D** (замер по пикселям, 285 текстов, 15 состояний на десктопе и телефоне):
  первый экран ≥ 7,9 : 1 (нужно 7), «Огонь» ≥ 5 : 1, остальное ≥ 4,5 : 1.
- **Контент без WebGL и анимаций**: весь текст и бриф — в HTML (`e2e/site.spec.ts`, без JS).
- **Клавиатура**: меню (фокус внутри, Esc возвращает фокус), навигация-горизонт, развилка,
  вращение юрты стрелками, табы стрелками, лента кейсов (Enter — переход), бриф.
- **Порядок фокуса при смене порядка форматов**: порядок DOM = порядок табов = порядок Tab.
- **Проявление светом** доходит до полной яркости у всех видимых текстов.
- **reduced motion**: режим «Коротко», холст не создаётся, видео нет, анимаций нет.
- **Увеличение 200–400%**: бриф и главная без прокрутки вбок, у всех полей подписи;
  при ширине < 600 px бриф — «строка + поле».
- **Озвучивание**: ошибки — сводка в `aria-live` + текст у поля + `aria-invalid`, фокус на первом
  поле с ошибкой; успех — `role="status"` с фокусом; сбой отправки — `role="alert"`.
- **Ориентиры**: один `<h1>`, главы — `section aria-labelledby`, холст `aria-hidden`.

Автотесты: `e2e/a11y.spec.ts` (axe по страницам), `e2e/a11y-flows.spec.ts` (3D-состояния, дерево
доступности, табы, 400%, контраст над 3D, путь клавиатурой на трёх языках), `e2e/locales.spec.ts` (lang).

## Не решено / ограничения

- **Кнопки блюд «Огня»** при очень быстром Tab (чаще раза в полсекунды) секунду видны прозрачными,
  пока камера доезжает до вида сверху. При обычном темпе — видны сразу.
- **Казахская версия** читается русским голосом, пока нет текстов копирайтера (TODO(kk-copywriter)).
  Когда перевод будет частичным, нужно отмечать непереведённые строки `lang="ru"` (WCAG 3.1.2).

## Ручная проверка скринридером (нужно пройти до запуска)

Путь — на трёх языках (`/kk`, `/ru`, `/en`): **найти формат → отправить бриф**.

**VoiceOver** (macOS Safari: ⌘F5; iPhone: Настройки → Универсальный доступ → VoiceOver)
**NVDA** (Windows, Chrome и Firefox: nvaccess.org, бесплатно)

1. Открыть главную. Услышать: «Мы ставим мир», заголовок 1-го уровня; описание сцены рассвета.
2. Ротором / клавишей H — по заголовкам: главы в порядке сюжета, у каждой — описание сцены.
3. Дойти до «Мир готов», табы «Форматы событий»: стрелками — до «Кудалык», услышать «выбрано».
4. Tab — в панель, «Обсудить кудалык» — Enter. Услышать диалог «Расскажите о событии»,
   «Кудалык» — выбран.
5. Сразу «Отправить бриф»: услышать сводку ошибок, фокус — на поле имени, «недопустимое значение».
6. Ввести имя, телефон, отметить согласие, отправить: услышать «Спасибо! Заявка у нас».
7. Повторить с увеличением 200% и с включённым «уменьшением движения».

Отметить в таблице: язык × скринридер × браузер → пройдено / что не услышали.
