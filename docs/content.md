# Контент

## Где лежат тексты

- `src/content/messages/ru.ts` — русский, базовый язык. Его структура — эталон.
- `src/content/messages/kk.ts` — казахский. `TODO(kk-copywriter)`: пишет копирайтер-носитель,
  машинный перевод запрещён. Недостающие ключи автоматически берутся из ru.
- `src/content/messages/en.ts` — английский черновик, `TODO(en-review)`. Должен содержать все ключи ru
  (проверяет тест).
- `src/content/type-specimen.ts` — тестовые строки для страницы `/[locale]/type-test`.

## Типографика

Строки прогоняются через `typograph(text, locale)` из `src/lib/typography.ts`:
кавычки, тире, неразрывные пробелы после коротких слов, в числах и телефонах.
Для казахского списка коротких слов пока нет — `TODO(kk-copywriter)`.
